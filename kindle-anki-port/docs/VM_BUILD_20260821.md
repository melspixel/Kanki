## QEMU gate status

A target-independent ARM QEMU smoke harness and `run-qemu-smoke.sh` have been added in the local source checkpoint. The harness itself cross-compiles as ARMv7 hard-float. The current VM does not yet have a checksum-verified full PW6 rootfs mounted, and installing `qemu-user` from the VM package network timed out. QEMU execution is therefore pending; this does not require the user's local host.
