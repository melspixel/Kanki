# Kindle Anki Port — GitHub source archive

This branch is an immutable archival snapshot of the independent desktop-Anki-to-Kindle port source. It does not contain or depend on RAnki, `rewrite-v1`, or the separate V1 project.

GitHub stores the binary ZIP as Base64 chunks so the snapshot can be preserved through the repository connector. To restore it on macOS/Linux:

```sh
chmod +x restore.sh
./restore.sh
```

The expected SHA-256 is recorded in `Kindle-Anki-Port-source.zip.sha256`.
