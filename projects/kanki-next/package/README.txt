Kanki Next renderer probe

Install:
1. Copy this kanki-next directory to /mnt/us/extensions/kanki-next/
2. Launch through KUAL.
3. Exit with the native button.
4. Run the report collector menu item.
5. Retrieve /mnt/us/documents/KankiNextProbeReport.txt

This probe does not open or modify /mnt/us/anki_data.
It validates Kindle WebKit CSS-pixel, full-content-zoom, viewport, font, image,
and persistent reviewer behavior before the full Anki application is integrated.
